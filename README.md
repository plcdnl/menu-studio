# Menu Studio

Strumento minimale per impaginare il menu di un ristorante pagina per pagina ed esportarlo in PDF A4.

- **Landing page:** `index.html`
- **Strumento:** `app/index.html` — un singolo file HTML, nessuna dipendenza, nessun server.

## Uso

Apri `app/index.html` in Chrome, Edge o Safari. I progetti si salvano come file `.json` sul computer; l'esportazione PDF passa dalla finestra di stampa del browser («Salva come PDF»).
